# 📄 PDF AI Summarizer

A Streamlit app that summarizes PDF documents with **Google Gemini** (via LangChain). Upload a PDF, pick a style, and get a summary, a structure analysis and optional key quotes.

![Python](https://img.shields.io/badge/python-3.11%2B-blue)
![Streamlit](https://img.shields.io/badge/Streamlit-1.40%2B-FF4B4B)

## What it does

- Extracts and cleans text from a PDF, then splits it into token-limited chunks
- Summarizes each chunk, then combines them into one final summary (map → reduce)
- Four summary types:
  - **brief**: 2-3 sentence overview
  - **detailed**: key points, arguments and conclusions
  - **bullet_points**: scannable bullet list
  - **executive**: business-focused insights and recommendations
- Analyzes document structure and extracts key quotes (both optional)
- Shows the PDF metadata (pages, title, author, subject)
- Exports the summary as text and per-chunk statistics as CSV

## How it works

```
PDF → extract text → clean → chunk (by tokens)
                                  │
                  ┌───────────────┼───────────────┐
                  ▼               ▼               ▼
             summary 1       summary 2   ...  summary N      (map)
                  └───────────────┼───────────────┘
                                  ▼
                        combine → final summary             (reduce)
```

Each chunk is summarized independently and concurrently (4 at a time). Failed chunks
are marked in the UI and excluded from the combine step, so one bad chunk never
sinks the whole run.

## Setup

Requires Python 3.11+.

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env      # Windows: copy .env.example .env
```

Get a free API key at [aistudio.google.com/apikey](https://aistudio.google.com/apikey) and set
`GEMINI_API_KEY` in `.env`. `GEMINI_MODEL` sets the default model (it can also be
changed in the sidebar).

```dotenv
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-3.1-flash-lite
```

## Run

```bash
streamlit run app.py
```

Then open the URL Streamlit prints (usually http://localhost:8501).

## Configuration

| Variable | Default | Purpose |
|---|---|---|
| `GEMINI_API_KEY` | – | Required. Google AI Studio key. Never commit it. |
| `GEMINI_MODEL` | `gemini-3.1-flash-lite` | Default model; any model your key can access works. |

Sidebar controls: model, summary type, max tokens per chunk (4000–10000),
document analysis on/off, key quotes on/off.

## Prompt templates

All prompts live in `prompts.py` as LangChain `ChatPromptTemplate`s (system + human message):

- `STYLES`: dict mapping each summary type to its instruction text (injected as `{style}`)
- `_template(human)`: helper that builds a `ChatPromptTemplate` from the shared system message plus a human message
- `CHUNK_SUMMARY`: per-chunk summary prompt (takes `{style}` and `{text}`)
- `COMBINE`: merges chunk summaries into the final summary
- `ANALYSIS`: document structure analysis
- `QUOTES`: key quote extraction

To add a new style, add an entry to `STYLES` in `prompts.py` and add its name to the
"Summary Type" options in `app.py`.

## Tests

```bash
pip install -r requirements-dev.txt
pytest -q
```

The suite is fully offline: `tests/test_summarizer.py` injects a fake chat model
into `PDFSummarizer`, so no API key and no tokens are spent.

For a live end-to-end check (costs one or two API calls):

```bash
python scripts/make_sample_pdf.py sample/sample.pdf
python scripts/smoke_test.py
```

## Cost and speed

A run makes `N + 1` LLM calls (map + reduce), plus one each for analysis and quotes.
A 30-page PDF typically splits into 3–6 chunks. Use a flash-lite model for speed and
low cost, or the chunk-size slider to trade calls against context quality.

## Troubleshooting

- **"No extractable text"**: the PDF is probably scanned images. Run OCR on it first.
- **429 / rate limit errors**: wait a minute and retry, use a smaller document, or switch to another model.
- **Model not available / 404**: set `GEMINI_MODEL` in `.env` (or pick another model in the sidebar) to one your key can access.
- **API key not found**: make sure `.env` exists next to `app.py` and contains `GEMINI_API_KEY`.
- **Results disappear on download click**: they shouldn't — results are stored in `st.session_state`; if you see this, check the browser tab did not reload.
