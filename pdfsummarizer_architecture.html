Reduce

COMBINE merges section summaries into one de-duplicated final summary. If it fails, joins sections as a fallback.

State and side channels

Session state

Stores processor, current file id and results, so download clicks never re-run the pipeline.

Cache

@st.cache_resource keeps one Gemini client per model across reruns and sessions.

Analysis

ANALYSIS on the first 3000 chars: type, themes, sections, audience, purpose.

Quotes

QUOTES on the first 5000 chars; numbering and quote marks stripped, capped at 10.

Outputs

Summary text

Styled per choice: brief, detailed, bullet points, executive.

Statistics

Per-chunk lengths, compression ratio, success rate, estimated runtime.

Exports

Plain-text report (.txt) and statistics table (.csv).
